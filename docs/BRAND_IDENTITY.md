# Floorfi — Brand Identity

## Name
**Floorfi** — floor + DeFi. Short, meme-native, product-clear.

## Positioning
The launchpad where memecoin volume literally mops NFT floors. Not a generic pump clone — a fee→sweep machine with receipts.

## Personality
- Smug janitor of Solana culture
- Transparent, slightly chaotic, never corporate
- Confident one-liners, no “Web3 synergy” speak

## Logo
- **Mark:** Rounded square (`#07080C` fill). Stylized mop head forms a geometric **F** in negative space. Accent glow `#3DFF9A`.
- **Wordmark:** `floorfi` lowercase, Space Grotesk Bold, `#F4F6FB`.
- **Lockup:** Mark left, wordmark right, 12px gap. Clear space = height of the “f”.
- **Don’t:** Add gradients to the wordmark, outline the mop in purple, use Comic Sans / Inter for logo.

## Typography
- Display: Space Grotesk
- UI: Inter
- Mono: JetBrains Mono

## Voice
- “Memecoins that mop the floor.”
- “Trade the coin. Sweep the collection.”
- “Floor mopped.” (success)
- Avoid: disrupt, leverage, ecosystem, revolutionary

## Promo usage
- Dark backgrounds only for ads.
- Always show an NFT thumb + green mop accent when explaining the product.
- Include a Solscan-style receipt chip in at least one creative.
